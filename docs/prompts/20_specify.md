# 20 — /speckit.specify 프롬프트(요구사항/유저 스토리)

아래를 그대로 입력:

/speckit.specify
인구 약 10만의 가상 도시에서, 시민 개별 주소/직장/일정에 따라 이동하는 교통 시뮬레이션을 만든다.
목표는 도시게임에서 흔한 “무조건 최단거리로만 이동” 문제를 완화해, 우회/분산/병목이 자연스럽게 나타나게 하는 것이다.
현실 지도 데이터는 필요 없고, 도시 구조는 다음을 포함해야 한다:
- 소로/대로/도시고속도로(순환/방사) 계층
- 한강 같은 강/장벽과 3~5개 대교(병목)
- IC/램프, 주요 교차로
- 존: 베드타운(주거), CBD/번화가(상업), 공업지구, 혼합지구
시민은:
- 집/직장/여가 POI를 갖고
- 평일/주말, 시간대(아침/점심/저녁/밤)별로 다른 트립을 만든다.
교통은:
- 혼잡/사고/공사 이벤트에 반응하며,
- 일부는 우회하고 일부는 고집하는 ‘행동 다양성’을 보여야 한다.
학습:
- 외부 데이터 없이, 시뮬레이션 경험을 통해 점진적으로 경로 선택이 개선되는 메커니즘을 포함한다.
UI:
- 최소한의 네비게이터 스타일 지도(도로망+혼잡 레이어)와 시간/요일 토글을 제공한다.
성능:
- 인구 100k 도시를 “플레이 가능한 속도”로 돌리는 것이 목표다(정밀 교통공학 시뮬이 아님).
