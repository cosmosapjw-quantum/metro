# 10 — /speckit.constitution 프롬프트(권장)

아래를 그대로 Codex(또는 에이전트)에게 입력:

/prompts:speckit.constitution
MetroFlow는 인구 10만 규모 도시에서 동적 교통을 시뮬레이션한다.
원칙:
- 외부 데이터 학습 금지. 정책/모델 업데이트는 시뮬레이터 내부 경험(online)만 사용.
- 기본 정책은 안전한 baseline(혼잡 반영 최단경로/동적 퍼텐셜)이고, 학습 정책은 점진적으로 섞는다.
- JAX-first: 핵심 루프는 jit 가능한 순수 함수로 설계. 랜덤은 PRNGKey로 통제.
- 작은 diff, 작은 task. task는 검증 가능(테스트/스모크/불변량)해야 한다.
- 시각화는 코어 루프를 막지 않는다(비동기/다운샘플/프레임 스킵).
- 성능 목표: 100k 인구, active 10k~30k에서 2~10Hz 게임틱.
체크리스트:
- 보존량(차량/agent), 음수 queue 금지, capacity 위반 탐지
- 평일/주말 + 시간대 전환 테스트
- 재현성(시드 고정) 테스트
