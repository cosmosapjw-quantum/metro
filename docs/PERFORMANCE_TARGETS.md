# Performance Targets (인구 100k 기준)

하드 타깃은 “플레이 가능한” 수준의 실시간성이다. (정밀 교통 공학 시뮬레이터가 목표가 아님)

## 도시 스케일 가정
- 인구: 100,000
- 링크(도로 조각): 5,000 ~ 30,000 (도시 생성 옵션에 따라)
- 노드(교차로/IC): 2,000 ~ 15,000
- 동시 이동(active agents): 10,000 ~ 30,000 (rush hour)

## 틱/업데이트
- 게임틱: 0.1~0.5s (2~10Hz)
- 내비/정책 업데이트(그래프 임베딩, 퍼텐셜): 1~5s 간격
- 시각화 업데이트: 5~20Hz(프레임 스킵 허용)

## 목표 성능
- CPU-only: 2~5Hz에서 “도시 규모 데모” 가능
- GPU/JAX: 10Hz 근처 목표 (조건: 링크/agent 연산을 텐서화)

## 측정 기준
- step latency(ms), p95
- 메모리 footprint
- 안정성: queue 음수/폭발 여부, 보존량
- 행동 다양성 지표: OD 경로 엔트로피, 병목 분산
