# Feature Spec — 001 MetroFlow (Traffic + Self-learning routing)

## Problem
시티빌더에서 agent 기반 시민 이동은 종종 “최단거리 고착”으로 인해
- 우회로/대체 경로가 무력화되고
- 다리/IC 등 일부 간선에 과도하게 집중하며
- 사고/공사/시간대 변화에 대한 적응이 비현실적으로 단순해진다.

## Goal
- 시민 개별 agent(주소/직장/일정)를 유지
- 경로 선택이 확률적/행동적으로 다양해지도록 설계
- 외부 데이터 없이 online 경험으로 “조금씩” 개선
- 인구 100k에서 플레이 가능한 속도

## User stories
1) 플레이어는 도시 구조(대로/고속도로/IC/다리)와 존(주거/상업/공업/CBD)을 설계한다.
2) 시민은 평일/주말 및 시간대에 따라 집-직장-여가 이동을 한다.
3) 혼잡/사고가 생기면 일부는 우회하고, 일부는 고집한다(분산/병목이 자연스럽게 형성).
4) 시간이 지나면 학습으로 “자주 막히는 루트”를 일부 회피한다(하지만 항상 최적은 아님).
5) UI에서 시간대/요일 토글로 혼잡 패턴을 확인한다.

## Acceptance criteria
- 인구 100k 도시 데모에서 5분(시뮬 시간) 돌려도 수치 폭발/음수 queue가 없다.
- rush hour에서 병목이 생기되, 완전 고착(모든 차량 1개 경로)로 수렴하지 않는다.
- 평일/주말 패턴이 명확히 다르고, 시간대별 흐름이 달라진다.
- 시각화는 실시간으로 혼잡 레이어를 보여주고(프레임 스킵 허용), 조작(토글/슬라이더)이 가능하다.
